pi codemode

The model writes JavaScript; it runs isolated in a QuickJS sandbox and reaches the outside world only through a narrow bridge into the host’s real tool pipeline. Only the script’s output reaches the model.

sandbox boundary permitted ingress blocked at the boundary

The mechanism

A script is an async function body. It runs in its own worker thread and its own QuickJS wasm VM. It has no Node, file system, network, or timers — the only way out is the bridge.

One script run · one worker · one VM

Model writes JS

  • raw source, not JSON
  • optional // @options: line
code crosses the boundary once, as text
→code

QuickJS sandbox the boundary

  • wasm VM in a worker thread
  • fresh VM + worker per run
  • 256 MB heap cap
  • sees only tools, ALL_TOOLS, text/image/console, store/load, models
the bridge is the only exit
→bridge (JSON)

Host tool pipeline

  • runs ctx.executeTool(name, args)
  • validation, hooks, permissions all apply
  • real tools execute here, not in the VM
only script output returns to the model

Blocked at the boundary

  • no fs, process, require, modules — no Node APIs
  • no network — no fetch, no sockets
  • no timers — so a promise that can never settle fails immediately
  • no nested codemode — scripts cannot start other scripts

What a script sees

The full surface. tools.* and models.* go out through the bridge; everything else stays inside the VM.

tools.<name>(args)

Call any callable tool. Resolves to a string, or an object if the tool declares an output schema; rejects with an Error on failure.

bridge · out

ALL_TOOLS

Every callable tool as { name, description } — includes tools the description does not list.

discovery

searchTools(query, {limit?, namespace?})

Rank callable tools by relevance (BM25, default limit 8). Finds MCP tools by topic.

discovery

describeTool(name) · describeNamespace(name)

Resolve a tool’s description + TypeScript declaration, or a namespace’s info and tools.

discovery

text(value)

Append a text item (strings as-is, other values JSON). console.log/info/warn/error/debug do the same.

output

image(urlOrBlock)

Append an image: a base64 data: URL, an { image_url } object, or an MCP image block. Remote URLs are rejected.

output

return value · exit()

Top-level return adds the value like text(); exit() ends the script successfully.

output

store(key, value) · load(key)

Keep small JSON state across codemode calls. Writes persist as session entries per branch.

state

models.*

getModelsOfType, getAvailableOfType, getModelOfType, classify, generateImages. Non-LLM models, not chat.

bridge · models

What a tool call returns

The result handed back into the script depends on whether the tool declares an output schema.

Tool declaresScript receivesWhy
outputSchema its structuredContent Also for error results that carry one — MCP tools resolve to their CallToolResult, including isError.
no schema its text content, as one string bash returns { output, truncated, full_output_path?, exit_code, wall_time_seconds }.
failed / blocked / invalid rejects with an Error The error carries the tool’s error text. Use Promise.allSettled() to keep the successes.

Limits

Hard caps, so a runaway script can’t take the session down.

heap
256 MB
overrun throws InternalError: out of memory
output
16 MB / 100k
text + base64 chars, and text()/image()/console items
store
256 KB / 1 MB
per value, and total across keys
timeout
none by default
@options: timeout_ms is a hard deadline; the worker is terminated
model calls
4 in flight
classify / generateImages; the rest queue
no timers
stalls fail
a promise with no pending tool call can never settle — the script fails
