What is Codemode

Armin Ronacher's update on a year-old thesis — code is all you need. Codemode lets the model orchestrate tools with a script that runs in the harness, so intermediate results never have to become tokens.

lucumr.pocoo.org/2026/10/6/codemode/ 2026-10-06 · tagged ai, pi context: Pi 1.0 ships MCP via Codemode

01 The dividing line — brains vs. hands

Brain — the harness

One machine · trusted · owns the context

LLM — model + tool definitions = tokens
Codemode sandbox — QuickJS in WASM: no network · no filesystem · no timers · limited RAM · only tool calls in/out
Transcript — store() / load() stash state here
Harness-only APIs — image models, classifiers, sub-agents; no regular tool = no context waste
TRUST BOUNDARY
Hands — execution environment

Often the same machine — but a different filesystem & trust level

bash / CLI — composes programs; model learned the filesystem in training
Files & processes — overflow files, artifacts, servers, tests
Sandboxable — e.g. Gondolin sandboxes bash — but never the harness itself
…and whatever the hands touch, the brain only sees through tool results

Why tools must exist at all: bash can only compose programs that run. Injecting an image into the protocol (read, view_image) or spawning sub-agents needs harness-native tools.

02 Two ways to call a tool

A · regular tool call
LLM→ tool(args)→ hands run it→ result → context

Every result becomes tokens. Pi caps it at the trailing 2000 lines; anything more goes to an overflow file the agent must re-read — each read costs context again.

B · via codemode
LLM writes one script→ sandbox loops / fans out→ tools × n→ return value only

Large outputs arrive structurally in the sandbox, get filtered/aggregated in code — the LLM sees the distilled result. Same tool calls, a fraction of the tokens.

enters context: final return value enters context: every intermediate result (A)

03 What Codemode unlocks

Concurrency & workflows

Promise.all over 100 items; probe 5–10 results first, then script the rest. Pi caps concurrent tool runs at 4 and queues the rest.

State across calls

store(k, v) dumps into the transcript; the next invocation load()s it. Lives on the harness host — not the sandbox.

Harness-only model APIs

Image generation & one-shot classifiers were never viable as tools (they'd waste context) — via Codemode the agent reaches them directly.

MCP by progressive discovery

No MCP tool is exposed to the LLM's tool list at all — the agent searches for tools inside Codemode when it needs them.

for (const block of result.output)

  (await tools.mcp__sentry__find_organizations({})).structuredContent;

05 Modern MCP is a fight

MCP servers still target harnesses without Codemode — so they ship their own code-execution tools. The interim result: Codemode in Codemode — JavaScript funneled through JavaScript, double JSON escaping, and the inner code can't call the outer tools.

await tools.mcp__cloudflare__execute({
  code: `async () => {          // ← a string inside JSON inside JS
    const r = await cloudflare.request({ method: "GET", path: "/accounts" });
    return r.result.map(a => ({ id: a.id, name: a.name }));
  }`,
});
What MCP servers would need to change
  • Structured content — return clean JSON via outputSchema; many don't yet
  • Consistent results — no token-driven shape changes; a 5-item probe that breaks at batch size 100 kills the pattern
  • Large binary data — still unsupported; today it's pre-signed-URL workarounds outside MCP
  • Composable tool search — no mechanism to fan out searches across servers; all emergent, doesn't scale

06 Not a reversal — an extension

Thesis holds

A year of "prefer CLI over tool dumps" was vindicated: the MCP ecosystem converged on code. Codemode goes beyond MCP — a general freedom-expression mechanism inside the harness.

Open: durability

Long scripts can die mid-flight — ideas imported from durable workflow engines (snapshot invocations) are on the table.

Open: language fit

JavaScript's dynamism vs. determinism — maybe Starlark is the better composition language. Images, binary data, and small models remain unsolved.
